# Hi, I'm Yash

Senior Software Engineer at Netcore (Unbxd), Bengaluru. I build AI agent infrastructure and put it in front of real customers.

## What I work on

- **MCP platform:** I led the design and development of a multi-tenant Model Context Protocol server that lets AI agents operate Unbxd's e-commerce search and merchandising tools. It exposes 100+ tools, is live with 3 customers, and uses OAuth 2.1 so an agent cannot reach another customer's data. This is company code, so it is not public.
- **LLM evaluation:** an LLM-as-judge pipeline that scores AI-generated catalog data, simplified by measuring each stage before keeping it.
- **Customer-facing AI:** data modeling, integrations, and reusable agent skills that cut typical customer onboarding from 3 to 6 months to about 1 week.
